Terminologia oficial para a arquitetura de Identidade Autossoberana (SSI).

DID

fingerprint
Identidade

Decentralized Identifier. Um identificador globalmente único, altamente disponível e criptograficamente verificável, projetado para não depender de registros centralizados ou provedores de identidade.

Verifiable Credential

verified
Autenticação

Um conjunto de declarações invioláveis e verificáveis criptograficamente feitas por um emissor sobre um titular, representando atributos físicos ou digitais de forma padronizada (W3C).

ZKP

security
Criptografia

Zero-Knowledge Proof. Um método criptográfico pelo qual uma parte (o provador) pode provar a outra parte (o verificador) que uma determinada afirmação é verdadeira, sem revelar nenhuma informação além do fato de que a afirmação é verdadeira.

Issuer

domain
Atores

Entidade (como uma universidade) que emite Credenciais Verificáveis para um Titular (Holder) e assina criptograficamente essas credenciais.

Wallet

account_balance_wallet
Infraestrutura

Software ou hardware utilizado por um titular para armazenar, gerenciar e apresentar suas Credenciais Verificáveis e chaves criptográficas de forma segura.
